description: Process a test result into learnings and next ads (Evolve SOP 09 + copy SOP 08)
argument-hint: <brand> <ad/batch name + results, or a results file>
---
Args: $ARGUMENTS

1. Read `knowledge/evolve-course/playbook/sops/09-analysis-and-iteration.md`, `knowledge/evolve-course/playbook/frameworks/16-winning-ad-definitions.md` and `17-feedback-loops-and-learnings.md`, `knowledge/evolve-copywriting/playbook/sops/08-iterating-on-winners-and-losers.md` and `knowledge/evolve-copywriting/playbook/templates/iteration-playbook.md`. Use `knowledge/evolve-course/playbook/sops/08-scaling-and-managing.md` Part A for labels.
2. Get the numbers. Northbeam is Clicks only, accrual, 7-day. Ask for whatever's missing: spend, days live, CPA/ROAS vs KPI, hook rate, hold, CTR, CVR. Label the ad: Breakthrough / Spend Winner / KPI Winner / Loser.
3. Winner: do the winner breakdown and the ten-step learning process, then plan iterations and variations (named ITER#/BATCH#). Loser: run loser triage (`knowledge/evolve-course/playbook/templates/concept-and-brief-templates.md` §10). Was it execution, angle or research?
4. Write learnings as guesses ("we think... because..."), with the action plan, to `brands/<brand>/learnings.md`. Update the growth-guide row. If 3 attempts on one angle have failed, recommend retiring it (course L87).
5. End with the next 1–3 concrete ads, each ready for `/plan` or `/script`.
