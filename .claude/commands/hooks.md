Args: $ARGUMENTS

1. Read `knowledge/evolve-copywriting/playbook/sops/03-writing-hooks.md`, `knowledge/evolve-copywriting/playbook/principles/14-the-hook-framework.md` through `17-open-loops.md`, `18-bridges.md`, and `knowledge/evolve-copywriting/playbook/templates/hook-formulas.md`.
2. Pull the idea card from `brands/<brand>/growth-guide.md` (or build one with `/plan` first) plus the sub avatar's labels and quotes from `avatars.md`.
3. Write freely: 10+ hooks across formulas, targeted and broad, promise and open loop. Each one must fit the card's awareness level and angle. Pair the best ones with bridges.
4. Then fix ruthlessly: run the three checks (`knowledge/evolve-copywriting/playbook/principles/02-the-three-checks.md`) and cut to the top 3 hook + bridge pairs, with one line each on why it should stop this avatar.
5. Save to `brands/<brand>/ads/<idea-slug>.md` under "Hooks".
